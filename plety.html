One More Log

실시간 장작불 시뮬레이션 · Unreal Engine 5.8 · C++17

개발 중 1인 개발 · AI 구현

실제 시간으로 타들어 가는 장작불을 꺼지지 않게 돌보는 불멍 게임입니다. 자리를 비운 만큼 불이 정직하게 꺼지고, 장작을 어떻게 쌓느냐에 따라 화력과 타는 속도가 달라집니다.

맡은 부분

  • 게임의 핵심 방향 결정과 기획. 구현은 AI 도구 위주로 진행
  • 엔진과 분리한 C++17 결정론 연소 시뮬레이션 코어, 헤드리스 테스트 89건, 100시간 분량 따라잡기 계산 182ms
  • Nanite · Lumen 숲 장면, 불 닿은 쪽부터 숯과 재로 변하는 장작 머티리얼, 불 크기에 비례하는 Niagara 불티
  • 장작을 들고 회전해 떨어뜨리면 물리대로 굴러 자리 잡는 자유 배치

Digestor (이전 이름 Pill Agents)

2~4인 온라인 협동 3D 액션 · Unity 6 · URP · Netcode + Relay

개발 중 기획·개발 1인 · 모델링 협업 · AI 구현

위 속에 투입된 알약 요원이 되어 세균과 기생충 보스를 뚫고 탈출구까지 살아남는 게임입니다. 보스에 붙은 구슬을 때려 그로기 게이지를 채우면 딜 구간이 열리는, 팀이 직접 공격 타이밍을 만드는 구조를 설계했습니다.

맡은 부분

  • 기획과 설계를 직접 하고, 구현은 AI 도구 위주로 진행 (Claude Code 설계 검토 · Codex 구현 · 별도 검증)
  • 서버 권위 네트워킹 (Netcode for GameObjects + Relay)
  • 기생충 보스 3페이즈 상태머신
  • 밸런스 수치를 한 파일에서만 관리하는 GameBalanceConfig 구조
  • 물리 콜백 대신 SphereCast·OverlapSphere로 매 프레임 검사하는 판정 구조

SoulSync

2인 온라인 협동 로그라이크 · Unity 6 · Netcode + Relay

1인 개발

두 사람이 Unity Relay로 연결해 몬스터 웨이브를 돌파하는 던전 크롤러입니다. 속성(불꽃·얼음)과 무기(검·활)를 조합해 직업을 만들고, 레벨업 스킬·상점·가챠로 성장합니다.

맡은 부분

  • Netcode for GameObjects 기반 서버 권위 패턴으로 실시간 멀티플레이 구현
  • 보스 3종 패턴, 검·활 계열 스킬 시스템
  • 솔로 모드 분기를 포함한 게임플레이 루프
  • 기획부터 개발까지 혼자 진행한 1인 프로젝트

소개

가장 오래 붙잡았던 문제

적 AI가 의도대로 움직이지 않던 문제를 로그와 공식 문서를 오가며 원인을 찾을 때까지 파고들어 고친 적이 있습니다.

  1. 상태머신의 전이 조건을 하나씩 로그로 찍어 실제로 어느 상태에서 멈추는지부터 확인
  2. 조건을 바로 고치지 않고, Unity 공식 문서에서 해당 컴포넌트의 이벤트 호출 시점을 다시 확인
  3. 제가 가정한 호출 순서가 실제와 다르다는 걸 확인한 뒤에 조건문 수정

증상만 보고 코드를 바꿨다면 같은 문제가 다른 상태에서 다시 나왔을 것입니다.
